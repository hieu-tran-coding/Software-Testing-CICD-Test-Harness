# 📅 Chi Tiết Timeline - Tuần 4

## Mục tiêu chính
- Tập trung vào CI/CD (DevOps) hơn các phương pháp testing.
- Thay đổi công cụ CI: **GitHub Actions + Jenkins** (bỏ GitLab CI).

## Lịch trình
| Tuần | Hoạt động | Mô tả ngắn |
|------|-----------|-----------|
| **Tuần 4** | **1. Thiết lập Jenkins** | Cài đặt Jenkins server (Docker/VM), cấu hình pipeline cơ bản, tích hợp repo GitHub. |
| | **2. Tối ưu GitHub Actions** | Tạo workflow GitHub Actions cho build & test, chuẩn bị chuyển sang Jenkins cho deployment. |
| | **3. Thiết lập trigger Jenkins** | Kết nối webhook GitHub → Jenkins để tự động chạy pipeline khi có commit. |
| | **4. Tích hợp báo cáo** | Cấu hình Jenkins tạo Test Reports và lưu vào `docs/ai-audit-logs/`. |
| | **5. Vẽ sơ đồ CI/CD** | Vẽ sơ đồ CI/CD (GitHub → Jenkins → Deploy) và cập nhật tài liệu. |
| | **6. Kiểm thử & Đánh giá** | Chạy thử pipeline toàn bộ, ghi log, sửa lỗi, và viết hướng dẫn sử dụng. |
| **Tuần 5‑6** | **Triển khai Demo** | Chuẩn bị demo video, slide, và tài liệu cuối kỳ. |

> **Lưu ý:** Mọi thay đổi cấu hình CI/CD phải ghi lại trong `docs/ai-audit-logs/week-4/` theo quy định AI audit.
