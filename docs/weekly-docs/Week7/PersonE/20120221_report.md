## 3. Cách trình bày phần cá nhân

1. Nêu đầu vào: image tag theo SHA và Jenkinsfile lấy từ SCM.
2. Mở build pass: API smoke → 5 Cypress UI tests → JUnit/Allure.
3. Chạy ca tag sai hoặc HTTP 404; chỉ ra stage dừng và artifacts phục vụ chẩn đoán.
4. Kiểm tra cleanup, chạy lại ca pass; giải thích API client trả lỗi cho CI còn
   script demo xác nhận lỗi có chủ đích cho buổi trình bày.

Tài liệu chạy lại: [person-e-handoff.md](https://github.com/thu2005/realworld/blob/feature/person-e-handoff/docs/person-e-handoff.md).
