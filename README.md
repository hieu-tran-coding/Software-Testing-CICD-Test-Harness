# CI/CD Test Harness Project

This repository contains the deliverables for the seminar on building an automated test harness integrated with CI/CD pipelines.

## Jenkins / Person E

- [Báo cáo Week5](docs/weekly-docs/Week5/PersonE/week5_integration_report.md): nhận image GHCR, smoke test và cleanup.
- [Báo cáo Week6](docs/weekly-docs/Week6/PersonE/week6_report.md): 3 UI tests bổ sung, JUnit và demo pass/fail.
- [Báo cáo bàn giao Week7](docs/weekly-docs/Week7/PersonE/20120221_report.md): kiểm chứng Pipeline from SCM và hướng dẫn chạy lại.
- [Code và hướng dẫn Jenkins](https://github.com/thu2005/realworld/tree/next/jenkins): source nằm ở repo RealWorld, không nằm trong `src/` của repo tài liệu này.
- [Báo cáo tổng](docs/final-report/seminar-detailed-report.md) và [bài tập thực hành](docs/hands-on-exercises/README.md) do các thành viên khác biên soạn.
