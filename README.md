# CI/CD Test Harness Project

This repository contains the deliverables for the seminar on building an automated test harness integrated with CI/CD pipelines.

## Directory Structure
```
CI-CD-Test-Harness-Project/
├── .cicd-configs/                 # CI/CD pipeline configurations (e.g., GitHub Actions workflows)
├── docs/                          # Documentation and submission artifacts
│   ├── ai-audit-logs/             # AI usage audit logs per week
│   ├── meeting-proofs/            # Photos of group meetings, Jira board snapshots
│   ├── hands-on-exercises/        # Exercises and hints for the class
│   └── (other report, slide, log files)
├── src/                           # Source code of the sample application (case study)
├── test-harness/                  # Automated test scripts (UI, API, Data-driven)
├── scripts/                       # Helper shell scripts
└── README.md
```
